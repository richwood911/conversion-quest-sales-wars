# Enhanced README

Conversion Quest: Sales Wars is a satirical SNES-style arcade game built with Phaser 3 and influenced by the humor of Zombies Ate My Neighbors and the gritty edge of early Grand Theft Auto. You play as Richard Norwood, PMP and other unlockable sales professionals on a mission to maximize conversions across three frenetic levels. Each stage is a parody of real-world conversion funnels where shoppers, leads and friction come to life as moving characters.

## Gameplay Overview

* **Three stages** – Perfume counter, Shoe store, Car lot – each with unique layouts and objectives.
* **Customer types** – Warm leads, cold leads and reluctant leads, each requiring different tactics and awarding different scores.
* **Friction events** – Mall cops, angry managers and competitor salespeople chase you around the map, lowering morale and causing cartoon blood loss.
* **Weapons** – Spray bottle, boomerang shoes, scattershot keys and the ultimate infinite money gun unlock.
* **Finish moves** – Achieve over 90% conversion to trigger a Mortal Kombat-style finish sequence and perform creative "mortality" moves on friction pursuers.
* **Character unlocks** – Play as Richard Norwood or unlock Lisa the Brand Manager, the mysterious Alabrida operative and the MCP ‑9000 sales bot by achieving 95% conversions.
* **Prestige mode** – Unlock all characters to start a new game with the Infinite Money Gun and chase the perfect high score.

## Controls

The game is designed to be played with keyboard:

* **Arrow keys / WASD** – Move the character around the map.
* **Space bar / Z key** – Primary action (spray, throw shoes or throw keys depending on level).
* **Shift** – Dash / Sprint to avoid friction pursuers (consumes stamina).
* **E** – Handshake / close a deal once a lead is engaged.
* The interface displays your morale (health), conversion rate and timer.

## Running the Game

You can run Conversion Quest in your browser by serving the project files locally or deploying to GitHub Pages.

### Local Development

1. Clone the repository:

    ```sh
    git clone https://github.com/<your-username>/conversion-quest-sales-wars.git
    cd conversion-quest-sales-wars
    ```

2. Open `index.html` in any modern browser. No build tools are required as the project uses Phaser 3 via a CDN.

### Deploy to GitHub Pages

1. Commit your changes to the `Portfolio` branch (or `main`).
2. On GitHub, go to **Settings → Pages**, and under **Branch**, select `Portfolio` and the root folder.
3. Save. After a few minutes your game will be available at `https://<your-username>.github.io/conversion-quest-sales-wars`.
